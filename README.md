# Πρόγραμμα Ανάπτυξης U11 / U9

Read-only σελίδα για σύλλογο και γονείς. Τα δεδομένα ζουν σε ένα Google Sheet· η σελίδα τα διαβάζει μέσω ενός μικρού Apps Script. Δεν υπάρχει server ούτε βάση.

```
Google Sheet ──► Apps Script (JSON, μόνο ό,τι επιτρέπει η καρτέλα «Δημόσιο»)
                        │
                        ▼
         GitHub Pages: index.html + js/  ──► κινητό / υπολογιστής
```

## Αρχεία

| Αρχείο | Τι έχει |
|---|---|
| `index.html`, `css/style.css` | Η σελίδα |
| `config.js` | Το URL του API. Κενό = μόνο τοπικά δεδομένα |
| `js/content.js` | Κείμενα, μπλοκ σεζόν, μέθοδος, τεστ (ό,τι δεν είναι στο Sheet) |
| `js/diagrams.js` | Τα σχέδια γηπέδου ως δεδομένα + η σχεδίασή τους σε SVG |
| `js/drills.js` | Τοπικό αντίγραφο ασκησιολογίου (εφεδρικό) |
| `js/app.js` | Σχεδίαση των καρτελών |
| `js/live.js` | Φέρνει τα δεδομένα από το API και ξανασχεδιάζει |
| `apps-script/Code.gs` | Ο κώδικας που μπαίνει στο Sheet |
| `data/diagrams.json`, `data/svg/` | Τα σχέδια για χρήση εκτός σελίδας |

## Στήσιμο (μία φορά)

### 1. Apps Script
1. Άνοιξε το Sheet → **Επεκτάσεις → Apps Script**.
2. Σβήσε ό,τι υπάρχει στο `Code.gs` και επικόλλησε το `apps-script/Code.gs`. Αποθήκευση.
3. Πάνω, διάλεξε τη συνάρτηση `testAll` → **Εκτέλεση**. Την πρώτη φορά ζητάει άδεια: δώσ' την με τον λογαριασμό σου. Στο «Αρχείο καταγραφής» πρέπει να δεις JSON.
4. **Ανάπτυξη → Νέα ανάπτυξη** → τύπος **Εφαρμογή ιστού**.
   - Εκτέλεση ως: **Εγώ**
   - Ποιος έχει πρόσβαση: **Οποιοσδήποτε**
5. Αντέγραψε το URL που τελειώνει σε `/exec`. Άνοιξέ το σε browser με `?r=index` στο τέλος: πρέπει να δεις τη λίστα των πόρων.

> «Οποιοσδήποτε» σημαίνει ότι όποιος έχει το URL βλέπει ό,τι επιτρέπει η καρτέλα «Δημόσιο», τίποτα παραπάνω. Ρόστερ, μηνιαίες παρουσίες, Σύνοψη, σημειώσεις για παιδιά, σκορ και album είναι μπλοκαρισμένα και μέσα στον κώδικα.

### 2. Σελίδα
1. Βάλε το URL στο `config.js` → `API_URL: "https://script.google.com/macros/s/…/exec"`.
2. Ανέβασε το repo στο GitHub → **Settings → Pages** → Source: `main`, φάκελος `/ (root)`.
3. Σε 1–2 λεπτά η σελίδα είναι στο `https://<όνομα>.github.io/<repo>/`.

## Καθημερινή χρήση

- **Νέα δεδομένα** (προπόνηση, παρουσίες, άσκηση, φιλικό): γράφονται στο Sheet. Η σελίδα τα δείχνει σε έως 5 λεπτά.
- **Νέα ενότητα δεδομένων**: νέα γραμμή στην καρτέλα «Δημόσιο». Το Apps Script δεν αλλάζει.
- **Αλλαγή στην εμφάνιση της σελίδας**: αλλαγή στα αρχεία `js/` και `css/`, σε ξεχωριστό branch, και merge αφού το δεις.
- **Αλλαγή στο `Code.gs`** (σπάνια): μετά την επικόλληση, **Ανάπτυξη → Διαχείριση αναπτύξεων → Επεξεργασία → Νέα έκδοση**, για να μείνει ίδιο το URL.

## Κανόνες

- Κανένα όνομα παιδιού στη δημόσια σελίδα.
- Φωτογραφίες μόνο με link, μόνο από τη στήλη «Δημόσια φωτογραφία», και μόνο όταν υπάρχει συναίνεση για δημόσια χρήση για κάθε παιδί που φαίνεται.
- Σκορ φιλικών δεν δημοσιεύεται.
